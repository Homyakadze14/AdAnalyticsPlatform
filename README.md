# AI-Powered Ad Analytics Platform

## Платформа для сбора, обработки и анализа в реальном времени данных о показах рекламы (ad impressions) и кликах (clicks). Система строит поведенческие профили пользователей и с помощью нейросети предсказывает вероятность клика (CTR) для оптимизации рекламных кампаний.

### Стек:
- Go
- PostgreSQL
- Kafka
- Redis
- Kubernetes
- ClickHouse
- ML

### Паттерны:
- Микросервисная архитектура
- CQRS
- Event Sourcing
- Circuit Breaker
- Outbox Pattern
- API Gateway
